# Calibration fixtures

Issue #3 owns this directory.

Each specimen should eventually provide machine-readable exact data for:

- dimension;
- prototile identifiers;
- substitution rule;
- expansion matrix/operator;
- child placements;
- control-point convention;
- arithmetic domain;
- declared hypotheses;
- literature source for expected status;
- expected authority class;
- replay digest.

Penrose is one positive fixture, not the corpus definition.

Do not commit floating-point geometry as an acceptance oracle. Derived visualizations may be stored separately and labelled non-authoritative.
