# Hypothesis firewall

**Status:** normative research policy, not a mathematical theorem.

The following assumptions must never enter a theorem silently.

| Hypothesis | Default status | Required action |
| --- | --- | --- |
| primitivity | explicit | state in class definition |
| aperiodicity | explicit/derived | record proof or source |
| FLC | explicit/derived | record exact source |
| repetitivity/minimality | derived/imported | do not conflate with primitivity without hypotheses |
| self-similar expansion | optional | distinguish from general self-affine |
| diagonalizable expansion | optional | state where used |
| Pisot-family spectrum | optional | state exact definition and multiplicities |
| Meyer return vectors/control points | optional | prove or import from exact hypotheses |
| connected prototiles | optional | never infer from substitution matrix |
| non-rod condition | optional | keep theorem-specific |
| representability of a substitution Delone set | optional | prove before geometric use |
| unimodularity | prohibited as hidden restriction | separate unit/non-unit branches |
| Euclidean internal space only | prohibited as hidden restriction | non-unit cases may need non-Archimedean factors |
| regular model-set status | strong conclusion/assumption | if assumed, do not market resulting PDS as new |
| overlap coincidence | target, not premise | unless calibrating an imported theorem |
| algebraic coincidence | target/equivalent criterion | status depends on audited theorem |
| finite overlap graph | theorem obligation | capped enumeration is not proof of finiteness |
| exact tile intersection | theorem/computational obligation | floats are not certificates |
| Penrose geometry | calibration only | never a class hypothesis |

## Counterexample discipline

A failed proposed lemma must be retained as a replayable negative fixture containing:

- substitution/tile data;
- expansion matrix;
- exact overlap state(s);
- recurrence/cycle witness;
- hypothesis checklist;
- which asserted implication failed.

## Status discipline

Use:

- **proved** — repository proof at the stated generality;
- **imported** — literature theorem with exact hypotheses audited;
- **finite-domain** — exhaustive theorem on a finite declared domain;
- **conditional** — proof valid assuming named open premises;
- **open** — unresolved mathematical statement;
- **bridge** — proposed implication/interface not yet proved;
- **evidence** — empirical/computational observation;
- **retired** — superseded or refuted route.
