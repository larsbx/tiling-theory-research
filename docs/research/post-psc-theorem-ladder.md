# Post-PSC theorem ladder

**Status:** candidate research plan.

## T0 — calibration

Construct the exact overlap object for several independently understood positive and negative specimens. This is regression/evidence work, not the class theorem.

## T1 — representation and completeness

Open target: under explicit hypotheses \(H_{rep}\), connect the executable overlap object to the complete realized overlap classes required by the selected imported coincidence criterion.

Required components:

1. exact translation/displacement module;
2. exact tile-overlap predicate;
3. child-overlap inflation law;
4. realization of generated states;
5. completeness for all relevant realized overlap classes;
6. exact agreement of coincidence states with full-tile coincidence.

No state or collar cap substitutes for completeness.

## T2 — automatic coincidence

Open flagship target: choose a natural class \(\mathcal C\) and exclude every recurrent noncoincident component for every member of \(\mathcal C\).

Working contradiction shape:

```text
failure of coincidence
=> complete finite recurrent noncoincident component S
=> exact expansion/translation recurrence on S
=> class-specific rigidity
=> contradiction
```

## T3 — spectral consequence

Conditional architecture:

```text
T in C
=> T2 coincidence result
=> audited imported spectral theorem
=> pure discrete dynamical spectrum
```

## T4 — enlarge the class

Candidate relaxations include connectedness, self-similar versus self-affine expansion, model-set adjacency, non-unimodular/adelic factors, and broader Pisot-family/homological-Pisot settings. Relax one hypothesis at a time and identify the first lemma that fails.
