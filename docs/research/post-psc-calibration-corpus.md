# Post-PSC calibration corpus

**Status:** candidate corpus design. Results remain specimen-level unless separately registered and certified.

The corpus must test the higher-dimensional abstraction, not merely reproduce one named tiling.

## Positive families

Candidate coverage should eventually include:

1. Penrose substitution tilings as one classical pure-discrete/model-set calibration;
2. at least one non-Penrose planar self-similar family with an independently sourced coincidence/model-set description;
3. at least one genuinely self-affine, non-scalar expansion if the selected theorem class permits it;
4. a non-unimodular specimen if the selected theorem class permits it.

Exact specimens should be pinned only after the literature audit identifies a reliable expected verdict.

## Negative controls

Include systems outside the selected theorem class or systems whose spectrum/coincidence behavior is independently known not to satisfy the target conclusion. Their role is to check that either:

- the hypothesis gate rejects the specimen; or
- a recurrent noncoincident obstruction survives.

## Fixture record

Each specimen should record:

```text
name
dimension
prototile types
substitution rule
expansion Q
control-point convention
exact coordinate/algebraic domain
declared hypotheses
source for expected spectral/coincidence status
overlap-state digest
computed result
repository status / authority
```

## Initial acceptance target

Before executable work is used in a class-wide argument:

- at least three positive families;
- at least two negative controls;
- one nontrivial recurrent noncoincident or hypothesis-rejection fixture;
- exact replay from committed data;
- no uncited expected verdict.
